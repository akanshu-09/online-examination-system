## 1. Know what controls what

- `.landing-nav`: logo and navigation arrangement.
- `.landing-hero`: shared hero spacing and vertical alignment.
- `.landing-login-landing-main`: landing page column widths.
- `.landing-hero-content`: text box position and text alignment.
- `.landing-cta-row`: button arrangement.
- `.landing-login-visual`: illustration styling.
- `.landing-nav-logo`: logo size.

## 2. Put text and image side by side or stack them

Edit `.landing-login-landing-main`:

```css
/* Two equal columns */
.landing-login-landing-main {
  grid-template-columns: 1fr 1fr;
}
```

To stack them, replace that property with:

```css
grid-template-columns: 1fr;
```

The original column sizes are:

```css
grid-template-columns: minmax(0, 1fr) minmax(320px, 0.9fr);
```

Keep the original value when restoring the current design. To put the image on the left and text on the right, swap their two child elements in JSX. Explicit positioning and responsive `order` rules can affect their final order.

## 3. Move the text box or align its text

Edit `.landing-hero-content`:

```css
.landing-hero-content {
  justify-self: end;
  align-self: start;
  text-align: right;
}
```

- `justify-self`: horizontal position inside the grid column — `start`, `center`, or `end`.
- `align-self`: vertical position inside the grid row — `start`, `center`, or `end`.
- `text-align`: text alignment inside the box — `left`, `center`, or `right`.

This example places the box at the top-right of its own grid area and aligns its text right. Movement needs spare space; a full-width box cannot visibly move horizontally. It does not move into another column.

To align both hero children vertically, edit `.landing-hero` and use `align-items: start`, `center`, or `end`.

## 4. Move or stack buttons

Edit `.landing-cta-row`:

```css
.landing-cta-row {
  display: flex;
  justify-content: center;
  gap: 14px;
}
```

For a horizontal Flexbox row:

| Arrangement | Property |
| --- | --- |
| Left | `justify-content: flex-start;` |
| Center | `justify-content: center;` |
| Right | `justify-content: flex-end;` |
| First left, last right | `justify-content: space-between;` |
| Stack vertically | `flex-direction: column;` |

Use the same alignment ideas on `.landing-nav` to arrange navigation items. When `flex-direction` becomes `column`, `justify-content` controls the vertical axis instead.

## 5. Understand responsive behavior

```css
@media (max-width: 860px) {
  .landing-login-landing-main {
    grid-template-columns: 1fr;
  }
}
```

At 860px wide or below, the layout becomes one column. The smaller mobile breakpoint is 640px. Responsive overrides are grouped at the end of the cleaned stylesheet.

A change inside a mobile media query will not appear on a wider desktop window. Existing responsive rules also place illustrations before text/forms.

## 6. If a change does nothing

1. Check that you edited the correct selector.
2. Check whether another rule overrides the property.
3. Check whether the media query applies at the current window width.
4. Check whether the container uses Grid or Flexbox.
5. Check whether there is enough spare space for alignment to be visible.

`flex-direction` does not arrange the children of a Grid container. A Grid container can itself be a flex item, so properties such as `flex` or `align-self` can still matter.

1. Change the landing page from two columns to one.
2. Center the action buttons.
3. Swap the image and text in JSX.
4. Resize the window to demonstrate the responsive breakpoint.
5. Restore the original values after each experiment.

Edit the existing rules rather than repeatedly adding new overrides at the bottom. The snippets above show the properties to change; keep the other declarations in each rule.
